
/* 
** Model Attributes
**
** Name			the base name of the model
** SoundTemplate the name of the sound template associated with this model (see attributes\serversnd.txt)
** Type			the type of model 
**
**					0 = human
**					1 = animal
**					2 = vehicle
**					3 = "generic prop"
** Skeleton		the index of the skeleton (node set) for this model
** Mass			the mass of the model in dedit units
** HitPoints	the initial hitpoints for the model
** MaxHitPoints	the maximum hitpoints for the model
** Armor		the initial amount of armor for the model
** MaxArmor		the maximum amount of armor for the model
** Energy		the initial energy for the model
** MaxEnergy	the maximum energy for the model
** MinSearchTime the default minimum amount of time to search this model (as a body)
** MaxSearchTime the default maximum amount of time to search this model (as a body)
** ModelFile    the model's .ltb file
** Skin0-N      the name of the skin file dtx(s).
**              there can be any number of skins: Skin0, Skin1, ..., SkinN
** RenderStyle0-N   the name of the render style file ltb(s).
**                  there can be any number of render styles: RenderStyle0, RenderStyle1, ..., RenderStyleN
** HandsSkin    the player view hands skin
** AIOnly       FALSE if this model can be used in multiplayer.
** CanBeCarried	FALSE if the body is to big to pick up 
** AIIgnoreBody	TRUE if AIs should ignore bodies of this type
** Translucent	0 or 1 indicating whether or not the model contains translucent parts that need to be sorted
** FleshSurfaceType The name of the surface type to simulate when the model is taking damage without armor
** ArmorSurfaceType The name of the surface type to simulate when the model is taking damage with armor
** Animation    the animation text file
** DefaultAttachment0-N  the position and name of attachments that the model has by default
**                       specified as case-sensitive "Position, Name"  (e.g. "RightHand, Lantern")
** UnalertDamageFactor	the percentage of damage applied when the AI is in an Unalert state.
** LoudMovementSoundBute Name of a sound bute to play when the MOVE_LOUD_KEY is placed on a frame in the model.
** QuietMovementSoundBute Name of a sound bute to play when the MOVE_QUIET_KEY is placed on a frame in the model.
**
** AltHeadSkin0-N  Names of alternate head skins to randomly use if the characters HeadExtension is set to RANDOM
** AltBodySkin0-N  Names of alternate body skins to randomly use if the characters BodyExtension is set to RANDOM
**
** NameId		Id of a CRes string that will be used to display the characters name when looking at it.
**
** PlayerPainSoundDir	Name of the directory to look for the pain sounds to play when using this model as a player.
**			The full path of the directory is 'Game\Chars\Snd\XXX' by default the full path is 'Game\Chars\Snd\Player\'
*/

** Skeleton [node group] Attributes
**
** DefaultFrontDeathAni			the default death ani played if we are killed from the front
** DefaultBackDeathAni			the default death ani played if we are killed from behind
** DefaultFrontLongRecoilAni	the default long recoil ani played if we are cheezed from the front (humans only)
** DefaultBackLongRecoilAni		the default long recoil ani played if we are cheezed from behind (humans only)
** DefaultHitNode				the default node that is hit if we ever take damage not associated with a specific node
**
** LookAtTrackingNodes			the index of the tracking nodes used while looking at something.
** AimAtTrackingNodes			the index of the tracking nodes used while aiming at something
**                              both tracking nodes are optional, and default to none.
**
** NodeXXName					the name of the node
** NodeXXFlags					the properties on the node . Flags should be the **SUM** of any of the following:
**								
**								 0	--	(no special flags)
**								 1	--	"critical hit" node (head, for example)
**								 2	--	"talk" node (jaw, for example)
**								 4	--  "tire" node (usually rear wheels)
**								 8	--  "turning tire" node (usually front wheels)
**								16	--	"rotor" node (controls helicopter blades)
**								32  --  "eye" node (only one per ai!!)
**								64  --  "wall stick" node (if hit here with spear, try to stick to wall)
**								
** NodeXXFrontDeathAni			the specific death ani played if we are killed in this node from the front
** NodeXXBackDeathAni			the specific death ani played if we are killed in this node from behind
** NodeXXFrontLongRecoilAni		the specific LongRecoil ani played if we are killed in this node from the front (humans only)
** NodeXXBackLongRecoilAni		the specific LongRecoil ani played if we are killed in this node from behind (humans only)
** NodeXXDamageFactor			the factor by which damage received to this node is scaled
** 
** NodeXXParent					the TRUE parent of this node in the hierarchy
**								
** NodeXXRecoilParent			the parent of this node when we walk the parent chain during a recoil
**								
** NodeXXLocation				the body part associated with the node (for hit location tracking)
**								
**								0	--	unknown/unspecified
**								1	--	Head
**								2	--	Torso
**								3	--	Arm
**								4	--	Leg
**								
** NodeXXRadius					the radius around the node used for determining hit location
**
** NodeXXPriority				the priority around the node used for determining hit location
**
** NodeXXAttachSpears			the flag for specifying if this node can attach spears when the character is alive
**
*/
